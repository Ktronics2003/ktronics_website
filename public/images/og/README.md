# OG / Social images

Drop the following files here before launch:

- `og-default.jpg` — 1200x630, used as the fallback OG image for every page.
  Recommended: a clean Ktronics-branded composition with logo + tagline,
  on the brand near-black background. Plenty of clear space — link previews
  often crop edges.
- `ktronics-logo.png` — 600x600 PNG with transparent background, used for
  the Organization JSON-LD `logo` field.

Test the result at https://opengraph.xyz/ before launch.
